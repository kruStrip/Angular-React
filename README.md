# Angular и React

Практикум по дисциплине: доска заявок из глав справочника, автоматизация в n8n и проекты модулей.

**Стек:** Angular · React · TypeScript · n8n

## Что внутри

- `zayavki/` — доска заявок
- `projects/` — проекты модулей
- `avtomatizaciya/` — автоматизация в n8n
- `lectures/`, `materials/`, `docs/` — конспекты и материалы глав

## Запуск

Каждое приложение запускается из своей папки: `npm install` и `npm run dev`.

Демо: https://algorthimization-course-vvodnoe.vercel.app/angular-react/index.html

Материалы приходят через GitHub Actions — каждая отправка проверяется сборкой и линтером.
