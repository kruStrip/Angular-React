# Angular и React — проекты курса

Доска заявок для общежития колледжа (вариант «Общежитие»).

| Папка | Проект | Что сделано |
|-------|--------|-------------|
| [module 1](<module 1/>) | Проект модуля 1: доска заявок | React + TypeScript, заявки в `localStorage`, фильтр и поиск, уведомление о новой заявке в Telegram через n8n |
| [module 2](<module 2/>) | Проект модуля 2: доска заявок с базой | Заявки в PocketBase, загрузка с ошибкой и повтором, хук `useRequests`, обновление по событиям без F5, ИИ-диспетчер в n8n с кнопкой «Взять» в Telegram |

Подробности и снимки — в README каждой папки.
