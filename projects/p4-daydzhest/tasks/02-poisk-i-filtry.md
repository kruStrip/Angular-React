# Задание 2. Поиск, тег и «только непрочитанные»

## Что сделать

- Поле «Поиск»: ищет по заголовку и пересказу без учёта регистра, пробелы по краям
  не считаются частью запроса.
- Выбор одного тега: пункт «Все теги» плюс теги, которые реально есть в загруженных
  новостях, по алфавиту.
- Флажок «Только непрочитанные» прячет новости с отметкой «прочитано».
- Все три условия работают вместе.
- Над лентой счётчик «Показано N из M», где M — все новости, N — подходящие.
- Если ничего не подошло — `<p>Новостей не найдено</p>`.

## Правила проекта

- Отфильтрованный список **вычисляется при отрисовке** из входных состояний
  (запрос, тег, флажок, прочитанное). Отдельного состояния со списком нет.
- Отметки «прочитано» в этом задании ещё нет: новости считаются непрочитанными,
  флажок пока проверяется на пустом списке прочитанного.
- Поля подписаны через `<label htmlFor>`, используются нативные `input` и `select`.

## Готово, когда

- `npx tsc -b`, `npm run lint -- --deny-warnings` — без ошибок;
- `CI=true npm test` проходит, добавлены тесты:
  1. поиск по заголовку в другом регистре;
  2. поиск по пересказу;
  3. фильтр по тегу;
  4. поиск и тег вместе дают счётчик «Показано 1 из 3»;
  5. пустой результат показывает «Новостей не найдено»;
- в браузере: ввод в поиск, смена тега и флажок сразу меняют ленту и счётчик.
