# Задание 3. Отметка «прочитано»

## Что сделать

- У каждой карточки кнопка «Отметить прочитанным»; после нажатия она показывает
  «Прочитано ✓», а карточка становится бледнее.
- Повторное нажатие снимает отметку и возвращает карточке обычный вид.
- Прочитанное хранится в `localStorage` под ключом `digest-read` — массив `id` новостей.
- После перезагрузки страницы отметки на месте.
- Битая запись в `localStorage` не ломает страницу: считается, что прочитанного нет.
- Флажок «Только непрочитанные» из задания 2 начинает прятать отмеченные новости.

## Правила проекта

- В состоянии — массив `id`, не объект новости.
- `localStorage` читается один раз при создании состояния, запись — в `useEffect`.
- Кнопка — `<button type="button">` с `aria-pressed`, доступна с клавиатуры.
- Бледность карточки не должна снижать контраст текста: меняется фон и цвет рамки,
  `opacity` не используется.

## Готово, когда

- `npx tsc -b`, `npm run lint -- --deny-warnings`, `CI=true npm test` — без ошибок;
- добавлены тесты:
  1. нажатие меняет текст кнопки на «Прочитано ✓» и пишет `id` в `localStorage`;
  2. после размонтирования и новой отрисовки отметка сохраняется;
  3. повторное нажатие снимает отметку и убирает `id` из `localStorage`;
  4. с включённым флажком прочитанная новость исчезает из ленты;
- в браузере: отметить новость, нажать F5 — отметка на месте; выбрать тег и флажок —
  счётчик уменьшается.
