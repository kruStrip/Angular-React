# Задание 1. Загрузка дайджеста и карточки новостей (React 19, TypeScript, Vite)

## Что сделать

- `src/digest.ts` — функция `loadDigest(url)`:
  - загружает JSON `{"news": [...]}` с адреса, который приходит аргументом;
  - теги приходят строкой «ИИ, наука» — функция превращает их в массив строк;
  - новости сортируются от свежих к старым по полю `date`;
  - если ответ не `ok` — ошибка с текстом «Дайджест не загрузился: код N.»;
  - если адрес не задан — ошибка «Дайджест не загрузился: не задан VITE_DIGEST_URL.».
- `App.tsx` показывает новости карточками:
  - заголовок — ссылка на `link` в новой вкладке;
  - источник и дата со временем;
  - пересказ `summary`;
  - теги отдельными метками.

## Правила проекта

- Данные загружаются в `useEffect` один раз; состояния: список, загрузка, ошибка.
- Пока идёт загрузка — `<p role="status">Загрузка дайджеста…</p>`; при ошибке —
  `<p role="alert">` с текстом ошибки.
- Поиска, фильтров и отметки «прочитано» в этом задании нет.
- Адрес берётся из `import.meta.env.VITE_DIGEST_URL`, в коде его нет.
- Сеть в тестах подменена, настоящих запросов нет.

## Готово, когда

- `npx tsc -b` и `npm run lint -- --deny-warnings` — без ошибок;
- `CI=true npm test` проходит, в `src/App.test.tsx` два новых теста с подменённым `fetch`:
  карточки в порядке от свежих к старым и сообщение «Дайджест не загрузился: код 500.»;
- `src/digest.test.ts` проверяет разбор тегов из строки;
- `npm run dev` показывает новости из таблицы.
