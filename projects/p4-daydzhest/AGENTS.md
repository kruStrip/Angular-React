# Правила проекта «Дайджест новостей»

Проект модуля 4: страница читает JSON веб-приложения Apps Script из автоматизации
модуля 4 и показывает новости карточками.

## Стек и версии

- Node.js 24 (в CI), npm 11
- React 19.2, TypeScript 6.0, Vite 8.3
- Vitest 4.1 + Testing Library + jsdom
- oxlint 1.81

## Команды проверки

```bash
npx tsc -b                          # типы
npm run lint -- --deny-warnings     # линтер, предупреждения считаются ошибками
CI=true npm test                    # тесты
npm run build                       # сборка
npm run dev                         # http://localhost:5173/digest/
```

Работа считается готовой, только когда все четыре команды проходят без ошибок.

## Формат данных

`VITE_DIGEST_URL` возвращает JSON:

```json
{
  "news": [
    {
      "id": "https://habr.com/ru/news/123/",
      "date": "2026-11-16T09:10:00Z",
      "source": "Хабр",
      "title": "Заголовок новости",
      "summary": "Пересказ в двух предложениях.",
      "tags": "ИИ, наука",
      "link": "https://habr.com/ru/news/123/"
    }
  ]
}
```

- `tags` приходят **строкой** через запятую; на странице это массив строк.
- `date` — ISO-строка; новости показываются от свежих к старым.
- `id` — адрес новости, он же ключ для отметки «прочитано».
- Пустой `news` — нормальный ответ, а не ошибка.

## Правила кода

- `VITE_DIGEST_URL` читается только из `import.meta.env`; адреса в коде нет.
  В репозитории лежит `.env.example`, файл `.env` не коммитится.
- Данные загружаются в `useEffect` один раз. Состояния: список, загрузка, ошибка.
- Пока идёт загрузка — `<p role="status">Загрузка дайджеста…</p>`.
- При ошибке — `<p role="alert">` с текстом «Дайджест не загрузился: код N.».
- Поиск, тег и «только непрочитанные» — входные состояния. Отфильтрованный список
  вычисляется при отрисовке и в состоянии не хранится.
- Отметка «прочитано» хранится в `localStorage` под ключом `digest-read` как массив `id`.
- Все поля имеют подпись через `<label htmlFor>`; используются нативные `input`,
  `select`, `button` — страница должна работать с клавиатуры.
- Тексты интерфейса — по-русски, с «ё» и типографскими кавычками, как в заданиях.
- Никаких `any`, `@ts-ignore` и отключений линтера без записи в `ai-log.md`.
- Новые зависимости — только после согласования.

## Тесты

- Сеть всегда подменена: `vi.stubGlobal('fetch', ...)`, настоящих запросов нет.
- Каждый тест проверяет требование из задания, а не реализацию.
- Запрещено менять или удалять тест, чтобы сборка стала зелёной. Если требование
  и тест противоречат друг другу — остановиться и сообщить.

## Секреты

Ключ записи Apps Script и токен бота в проект не попадают: страница только читает
открытый адрес. `.env` с настоящим адресом в репозиторий не коммитится.
